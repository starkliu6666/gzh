# 金融公众号交互报告

打开同目录下的 `金融公众号监控_2026-10-14至2026-10-20.html` 即可使用。HTML 内嵌全部本次取得的文章数据、样式和交互代码，无需安装软件或启动服务器，报告不含 API 密钥。

- 时间范围：2026-10-14 至 2026-10-20，北京时间。
- 关键词：助贷、消金、消费金融、互联网金融、互金、金融监管、银行、乐信、度小满、奇富、拍拍、小赢、洋钱罐、贷后、催收。
- 本次接口实际返回 244 条关键词匹配记录，合并去重为 235 篇文章，涉及 183 个公众号。
- 左侧切换关键词，上方搜索标题或公众号，也可叠加公众号名称筛选。
- 支持阅读数、综合分、发布时间排序；默认每页 10 篇，可选 20 / 50 篇。
- CSV 导出覆盖当前筛选下的全部文章，不限当前页；采用 UTF-8 BOM 编码，便于 Excel 打开。
- 同一篇文章可能命中多个关键词。全部视图展示最高关键词综合分；切换关键词后展示对应匹配分。
- 点击文章标题，在新标签页打开公众号原文；访问原文需要网络。

## 重新生成报告

在项目根目录运行：

```powershell
python -X utf8 scripts/build_wechat_report.py --input reports/2026-10-21/wechat-search-results.json --output reports/2026-10-21/金融公众号监控_2026-10-14至2026-10-20.html
```

该命令只使用已保存的数据，不发起新查询、不消耗 API 查询额度。
